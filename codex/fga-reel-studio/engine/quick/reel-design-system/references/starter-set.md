# Starter set: fonts, styles and sounds

Everything here is free to use. Fonts are Google Fonts. Sounds were made from scratch for this plugin and sit in `assets/sounds/`.

## Fonts by job
| Job | Font | Feels like |
|---|---|---|
| Captions, punchy | Montserrat italic 900 | Loud, energetic |
| Captions, clean | Inter Tight 800 to 900 | Modern, plain |
| Key words, editorial | Instrument Serif italic | Soft, magazine |
| Titles, playful | Calistoga | Bubbly, friendly, great for a series name |
| Titles, editorial | Gloock | Big, elegant serif |
| Numbers and posters | Anton | Tall condensed caps |
| Labels | Archivo Black | Heavy, compact |
| Titles, modern | Bricolage Grotesque 800 | Chunky, current |

## Styles (the options sheet letters)
- **Captions:** A italic punch caps with an outline (key words in a color) · B bold sans with key words in a big serif italic · C heavy sans, key words change color · D small and clean, above the head
- **Titles and hook header:** A bubbly outlined · B bold sans plus a giant serif · C soft serif italic · D tall poster caps · E chunky modern sans
- **Number pop:** A giant yellow outlined · B giant white outlined · C giant butter serif
- **Word pops:** A serif italic words scattered around the head · B bubbly words scattered around the head
- **Always included:** numbered list cards (big number plus a ticked label up top), and small captions under any window.

## Sounds
| File | Use for |
|---|---|
| click1, click2, click3 | Typing ticks under text that types on |
| typing | A short typing run |
| pop | A word or card landing |
| sparkle | A reveal, such as a series title |
| chime | A done or tick moment (can clash with music, so offer it last) |
| ding | A single bright hit |
| swish, whoosh | Transitions |
| tick | A light count beat |
| boom | One big moment only |

Play sounds about 14 dB under the voice. If the reel will have music added in the app, prefer pop, sparkle and swish, which have no clear musical note.

For more sounds, point the person to the free sound effects on pixabay.com. Downloads from there can be used in their reels but can't be bundled into this plugin.
