# Handing over the finished reel

Make a folder `Ready to post` inside the work folder with:
- `<reel name> - final.mp4`: a copy of `final.mp4`. The reel name is the raw video's file name unless they gave the reel a name
- `COVER.jpg`
- `captions.srt`: for platforms that take a subtitle file

Then tell them, in plain words:
- The reel passed the safe zone check, so nothing will be hidden by Instagram's buttons or caption.
- Music: add it in the Instagram app if they want it, at about 10 to 15% so their voice stays clear. Talking reels can go without.
- Cover: when posting, tap Edit cover, then Add from camera roll, and pick `COVER.jpg`.
- Next reel: their design system is saved, so next time they only need the raw video.
