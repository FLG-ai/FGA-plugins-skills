# Structural tells and how to fix them

Word lists catch single words. This table catches shapes: the way a sentence or a paragraph is built. Each row is a trigger to rewrite, so if a draft matches one, change the structure and then check the sentence again.

## Sentence and paragraph shapes

| Tell | How it shows up | Fix |
| --- | --- | --- |
| Antithesis | "This isn't a newsletter, it's a community." | Keep the half that's true and say it plainly. The hard floor in SKILL.md sets the one exception. |
| Reversal contrast | "We put people first rather than process." "prioritizing speed rather than polish" | The antithesis turned around. Say what you do and leave out the foil. |
| Mirrored reframe | "You don't run the inbox. The inbox runs you." | One flat, uneven sentence that carries the real claim. |
| Decorative triplet | "simple, smart and scalable", or triads in back-to-back sentences | Keep the one item that does the work. |
| Setup question | "The outcome? Record sales." "Why should you care? Because..." | Say the thing. |
| Big-reveal hook | "Here's what no agency will admit about retainers:" | Make the point as your own observation. |
| Copula dodge | "The app serves as a hub for your team." "The venue boasts sweeping views." Also "functions as", "operates as", "represents", "features", "offers", "maintains", and "refers to" used for the thing itself ("Onboarding refers to the first week"). | Use "is" or "has". |
| Participial tail | "..., reflecting a deeper commitment to quality." Watch for sentence-end tails built on highlighting, underscoring, emphasizing, ensuring, reflecting, symbolizing, contributing to, fostering, encompassing, enhancing. | Delete it, or turn it into a real claim with evidence behind it. |
| Hedge stack | "It could be argued that, in some cases and depending on context, this may help." | See the hedge fix under Substance in SKILL.md. |
| Faceless authority | "Research suggests...", "Many experts believe..." | Name the source, own the claim, or cut it. |
| Vague association | "She was associated with the rebrand." "in connection with the launch" | Say the actual relationship: she led it, paid for it, wrote it. |
| Partial-list hint | "tools such as Canva, Notion and Gmail" when those three are the whole list | Drop "such as" when the list is complete. Keep it only when the examples stand in for more. |
| Brochure tone | "boasts a vibrant, diverse array of", "rich history", "a commitment to excellence", "exemplifies" | Write it like a friend describing the place or the product, with one fact a brochure would leave out. |
| Challenges then bright future | a closing section that admits "several challenges" and lands on a vague hopeful outlook, or headings like "Challenges and Future Outlook", "Awards and Recognition" | Name the one real problem with a fact, and stop. No "X and Y" heading built for symmetry. |
| False suspense | "But wait, it gets better." "Now for the twist." | Deliver the point. |
| Analogy reflex | "Think of it as a GPS for your finances." | Keep it only if it explains better than the plain description, ideally with something the reader handles every day. |
| Coined label | "the visibility trap", "the review robot", "an invoice machine" | Keep a label the writer defines in a sentence, that has parts or steps, and that returns in the same words. Cut a cute name for an ordinary thing and use the everyday name ("automated review requests"). |
| Stock saying | "Trust is the currency of sales." | Say what people do, in plain terms. |
| Inspirational swerve | a post about spreadsheet formulas that ends on what it means to be human | Finish on the concrete subject. |
| Explained ending | the scene, then a line saying why the scene mattered | Cut the line after the scene. See By format in SKILL.md. |
| Grandiosity | "a defining moment for the industry", "will reshape how we work forever" | Size the claim to the facts. Ordinary is believable. |
| Anaphora overuse | "We listen. We plan. We deliver." | Vary the sentences, unless it's one deliberate beat. |
| Synonym cycling | "The baker... The pastry chef... The small business owner..." | Choose one name and stick with it. |
| Repeated openings | three paragraphs in a row that each begin "When I..." | Merge them or change how they start. |
| Repeated emphasis word | "every single" showing up twice in a short post | Keep one and rephrase the other. |
| Flogged metaphor | a garden image (seeds, pruning, harvest) coming back five times | Use it once. |
| Fractal summaries | "Below, we'll cover..." and "...as mentioned above" | Delete every preview and every recap, and never announce a transition or build up before a point. |
| Signposted ending | "To wrap up," then a restatement, then an uplifting line | Stop on the last concrete point. |
| Heading echo | a heading "Why onboarding matters" followed by "Onboarding matters for several reasons." | Open with the content itself. |
| Prompt echo | "You've asked for a bio for a yoga teacher. Here it is." | Start with the answer. |
| List dressed as prose | "Reason one is... Reason two is..." | Fold the points into one connected argument. |
| Uniform staccato | "The plan is simple. The plan is cheap. The plan is fast." A run of short statements is a list dressed up as a story. | Combine the sentences or change their frames. |
| Wall of one-liners | a whole piece of single-line paragraphs of the same length, each a full-stop aphorism | Mix them with blocks, in the amounts the channels file sets. |
| Compressed line with nothing in it | "Fewer tabs, more sales." | Unpack it. If unpacking reveals no claim, cut it. A compressed line stays when it says something true in fewer words than the plain version. |
| Narrated feeling | "She felt a wave of relief when the form went live." | Name a feeling once, in the first person, tied to the moment ("I dreaded every Monday"). Never narrate feelings for someone else. |
| Buried lede | the news turns up in paragraph three | Move it up. See By format in SKILL.md. |
| Subject-verb gap | "The form, which we built in one evening after two double bookings in May, took over." | Put the subject and verb together at the front, then let the sentence branch to the right ("The form took over. We built it in one evening..."). |
| Buried verb | the action hidden in a -tion noun: "made a decision to", "carried out an evaluation of", "the implementation of the form was" | Use the verb: "decided", "evaluated", "we set up the form". |
| Left-branching opener | "Having spent three years running the studio from a text thread, Ines..." | Start with the subject and verb and put the background after ("Ines ran the studio from a text thread for three years, and then..."). |
| Emphasis tail | a fragment tacked on for weight: ", no exceptions.", ", day in, day out.", ", every step of the way.", "and that's it." | Cut it. If the repetition matters, build it into the sentence ("every Monday"). |
| Padding clause | "the orders that get placed", "the calls that come in" | Cut any clause that repeats what the noun already says. |
| Over-explained task | "sorting the returns and then logging them in a sheet so the team could see which ones were done" | Name the task and stop. Readers know why a sheet gets updated, so drop "so that" and "so we could" tails that state the obvious. |
| Unbridged jump | a worry sitting next to a fact with no link between them: "I thought customers would hate the price rise. A florist ordered twice as much." | Show how one led to the other ("I thought the price rise would drive people off. Then a florist doubled her standing order the week it went live."), or put them in separate paragraphs. |
| Clipped robot ask | a question with no subject used as the close: "Quick call Friday?", "Worth a look?", "Up for a chat?" | Ask in a full sentence, the way a person would ("If you have half an hour on Friday, I can take you through it."). |
| Both-sidesing | a counterpoint after every claim, everything upbeat and resolved | Take a position, name the one honest risk, and move on. Leave things unresolved when the facts are. |
| Copy for anyone | text that could sit on 50 rival websites | Include one detail true only of this writer or business. |
| Assumed household | copy that assumes who cooks, who earns, or what the reader can afford | Assume nothing about gender roles, family setup or money. |

## Formatting tells

| Tell | How it shows up | Fix |
| --- | --- | --- |
| Title Case headline | "Why Your Inbox Is Costing You Money" | Sentence case. |
| Colon-split title | "Inbox Zero: Why It Matters" | Delete the first half and see if the second stands alone. It usually does. |
| Bold-label bullet | "**Security:** we encrypt everything" | Write the sentence. |
| Emoji as furniture | emoji bullets, decorative ✅ 🧠 🔹, arrows | Emoji only when the writer's samples use them, and never as bullets, decoration or arrows. |
| Markdown residue | `**`, `##` or `[text](url)` in an email, DM, comment or caption | Plain text wherever markdown won't render. |
| Curly quotes in social copy | " " in a post or DM | Straight quotes in emails, DMs and social posts. |
| Table for a sentence | a two-row table that says one thing | Write the sentence. |
| Rectangular paragraphs | every block the same height on the page | Vary paragraph shape and length. |
| Bold everywhere | several bolded phrases per paragraph | Bold one thing a skimmer must not miss, or nothing. |
| Heading scaffolding | a heading that repeats the title, headings that hold only other headings, skipped levels (a ## straight to ####), several top-level headings in one piece | One title, then plain section headings only where a reader would scan for them. |
| Section dividers | a horizontal rule (---) between every section | Let the heading or a blank line do it. |
| Paste residue | chatbot citation junk left in the text: contentReference, oaicite, oai_citation, turn0search0, [cite: 1], attached_file, grok_card, utm_source=chatgpt.com in a link | Delete it, then check the claim it was pinned to still has a real source. |
| Placeholder left in | [Your Name], [Company], [insert stat], {{first_name}} in a finished piece | Fill it with the real detail or cut the sentence. |
| Invented source | a link that 404s, a study, book, DOI or page number that can't be found | Open every link and check every named source before it ships. If you can't find it, cut it. |
